# Claude Hopkins Archive

A visual, source-backed archive of advertisements and campaigns attributed to Claude C. Hopkins.

## Editorial standard

Every gallery record carries:

- the scan/image source
- a verification source for authorship, campaign or date where available
- attribution confidence
- date confidence
- notes where the evidence conflicts or is incomplete

The archive deliberately does **not** call uncertain dates or attributions facts.

## Repository-name note

The repository currently has a trailing full stop in its GitHub name: `claude-hopkins-archive.`. This project uses that exact repository because it is the repository currently available through the connected GitHub account.

## Public-domain / source handling

The historical advertisements themselves date from the public-domain era in the United States. Modern scan hosts and archive websites are credited on every record. The gallery stores source provenance separately from the historical work itself.
